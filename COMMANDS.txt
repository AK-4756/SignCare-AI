═══════════════════════════════════════════════════════════════════════════════
🆘 IF SOMETHING BREAKS
═══════════════════════════════════════════════════════════════════════════════

API won't connect:
   1. Check Terminal 1 is running "python app.py"
   2. Check it shows "Server running at: http://localhost:8000"
   3. Refresh browser (Ctrl+R or Cmd+R)

Camera won't work:
   1. Close browser completely
   2. Reopen it
   3. Go back to website
   4. Click "Allow" for camera

Port 8000 already in use:
   # Windows
   netstat -ano | findstr :8000
   taskkill /PID [number] /F
   python app.py
   
   # Mac/Linux
   lsof -i :8000
   kill -9 [PID]
   python app.py

No predictions:
   1. Good lighting
   2. Show hand clearly
   3. Hold still for 1 second
   4. Check API is connected (green)

Model not found error:
   python train.py

🔑 KEYBOARD SHORTCUTS
═══════════════════════════════════════════════════════════════════════════════

Press Number Keys:
   1 - Select 1st suggestion
   2 - Select 2nd suggestion
   3 - Select 3rd suggestion

Button Clicks:
   ▶ Start Camera     - Begin detection
   ⏹ Stop Camera      - Stop detection
   ➜ Add Space        - Move word to sentence
   🗑 Clear Word      - Delete current word
   🔊 Speak           - Speak the sentence
   💾 Save            - Save to history
   Clear Sentence     - Clear everything
